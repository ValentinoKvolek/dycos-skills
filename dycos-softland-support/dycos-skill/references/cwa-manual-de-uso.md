## 1.1 Ingreso a la aplicación En el Escritorio de Trabajo seleccionar el
icono de acceso directo al Sistema de Gestión, para ello posicionar el mouse
sobre el ícono Sistema de Gestión y
hacer doble clic. | | | Alternativa uso teclado: Con la tecla Tab posicionar el cursor sobre
el icono del Sistema de Gestión y pulsar la tecla Enter. 
## 1.2 Ingreso del usuario y clave de seguridad Mediante esta operación se accede
al Sistema de Gestión con las opciones de menú y derechos correspondientes a su
nivel de usuario. Se deberán ingresar los datos requeridos: USUARIO: Se ingresa el código de usuario
asignado por el Administrador del Sistema, este código quedará unido a todas las operaciones que ejecute en el
sistema. CONTRASEÑA: Palabra clave secreta que lo
identifica en el sistema. Posicionando el cursor sobre el botón
aceptar y presionando sobre el botón con el mouse o la tecla Enter del teclado
se accede a las opciones del menú principal del sistema que corresponden
al Usuario ingresado.

## 3- Registraciones | 
## 
## Se puede ingresar a esta opción a través de
las siguientes alternativas: Por medio de un doble clic del botón
izquierdo del mouse posicionado sobre ésta opción o desplazándose con las
flechas de cursor del teclado hasta llegar a la opción, ésta aparecerá
sombreada y presionando la tecla Enter del teclado. 
## 3.1 Concepto de Circuitos Las registraciones en el Sistema de Gestión
están organizadas a través de pasos o circuitos, estos pasos tienen un orden
que los une o encadena y no se puede registrar un paso si no está registrado su
paso anterior obligatorio. Así mismo todos los datos de un paso se heredan en
los pasos o circuitos siguientes. 
## 3.2 Tipos de Registraciones Existen dos tipos de registraciones: 
## De Proceso Parcial Son utilizadas en los siguientes casos: Cuando es la primera operación de un
circuito el primer paso-, debiendo registrar todas las características de la
operación; Para procesos en que se deban efectuar registraciones
parciales sobre operaciones ya existentes; Cuando se quiera visualizar el contenido de
una operación antes de efectuar una registración encadenada. 
## De Proceso Total Cuando no se deben realizar procesos
parciales y no se requiere el detalle de la operación anterior sobre la que se
basa la registración actual. 
## 3.2.1. Pantallas de Proceso Parcial Una vez que se accedió a la opción de la
registración se presentará una pantalla que variará en el contenido según la
registración que se va a efectuar, pero que presenta las siguientes
características comunes en cuanto a su formato: Pantalla Encabezado: Corresponde a la parte superior de la pantalla donde figuran los
datos generales de la registración. Pantalla Items: Corresponde a la parte inferior de la pantalla donde se ingresan o
visualizan los componentes detallados de la operación. Pantalla subítems: Es una pantalla que se despliega para algunas operaciones en las que
se debe profundizar con un detalle mayor datos adicionales de los ítems.
Corresponderá en el caso de estar activada una cruz azul. En algunos casos este
contenido será completado automáticamente por el sistema.

## 3.2.1.1 Tipos de Menú de Registraciones de Proceso Parcial a- Registraciones - Menú desplegable  En la fila superior de la pantalla se

indicando la función. Estas funciones se ejecutan posicionando el indicador del
mouse sobre el botón y presionando con un clic o enter del teclado. c- Registraciones - Menú contextual Se llama Menú Contextual al que aparece al
presionar el botón derecho del mouse. Este es un menú sugerido por el sistema y
varía en función de la ubicación de la pantalla donde nos encontremos. d- Registraciones - Teclas abreviadas Algunas funciones también se pueden
ejecutar a través de teclas abreviadas del teclado . Acompañamos una tabla con las
posibilidades.

## Pantalla de opción y Filtros Cuando un paso en un circuito posee un paso
anterior se presentan otro tipo de pantallas en las que guiados por un
asistente vamos a elegir sobre qué
operación ya registrada se va a trabajar. Existen circuitos que presentan la
opción de registrar tanto por un tipo de Proceso Parcial como Total. En algunos casos cuando se puede optar por
Proceso Total o Parcial aparece la siguiente pantalla donde a través de un
tilde se indicará qué tipo de registración se elige. En el caso de un circuito
con proceso opcional el tilde se puede colocar y remover con un clic del mouse
o con pulsar la barra espaciadora del teclado. En esta pantalla también podemos indicar
filtros o parámetros para agilizar el proceso. Al pulsar el botón Siguiente con el
mouse o con el cursor posicionado sobre
el botón a través del desplazamiento con la tecla Tab del teclado y en el mismo
presionando la tecla Enter, nos deriva a continuación a la siguiente pantalla Si se elige Proceso Total: Se señalan las operaciones a registrar y se
selecciona el botón Terminar. En el caso que el proceso del punto anterior
resulte satisfactorio se desplegará una pantalla como la que sigue: En el paso siguiente se puede imprimir el
comprobante o se puede salir del proceso a través de la opción Cerrar. En el caso que el proceso no pueda
completarse desplegará una pantalla como la que sigue, debiéndose verificar los
motivos del error: Si NO elige Proceso Total: En la pantalla inferior se elegirá el
registro que se desee y al pulsar el botón Terminar se desplegará una Pantalla
de proceso parcial. | 
## 4-Visualización, Exportación e Impresión de Informes | 
## | | | | | | | | Existen diferentes tipos de salidas para
los informes o reportes del sistema: Por pantalla: se visualiza en el monitor
del usuario. Por impresora: se envía a una impresora
local o de red, con la configuración de impresión determinable por el usuario
como desde cualquier aplicación de Windows. Se exporta a otras aplicaciones con
diferentes extensiones, txt, dbf, html, xls. Se envía por mail.
